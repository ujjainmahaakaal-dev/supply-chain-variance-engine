# Perishable Supply-Chain Variance & Post-Merger EBITDA Engine

An interactive **Decision-Intelligence & Operational Excellence simulator** built with **Python, DuckDB, and Streamlit** to demonstrate how multi-entity roll-ups and public nutrition programs (e.g., PM-POSHAN / institutional fulfillment) eliminate last-mile yield drift in high-velocity, zero-inventory supply chains (~4,00,000 daily perishable units, 4-hour shelf life).

### Architectural Thesis
In decentralized, multi-entity roll-ups, EBITDA erosion rarely stems from macro strategy—it stems from **unstandardized recipe masters, pre-indent portion drift (+12% to +25%), and uncalibrated small-batch outliers** across legacy processing units.

This engine models three non-disruptive governance controls:
1. **ERP Pre-Indent Tolerance Locks:** Automated SQL validation blocking kitchen indents exceeding standard `Portion × PAX` norms prior to store release.
2. **Cross-Entity Benchmark Harmonization:** Side-by-side unit scorecards exposing portion variance and outlier batching across decentralized sites.
3. **Menu-Engineering Substitution & Accompaniment Rationalization:** Quantifying annualized margin recovery without compromising nutritional or plate-fill standards.
